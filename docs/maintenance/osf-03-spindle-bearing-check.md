# Spindle bearing inspection after overload

> **Synthetic note.** Written for a personal portfolio project to demonstrate retrieval. It is not a real manufacturer procedure; do not use it on real equipment.

## When to use

An overstrain event can overload the spindle bearings even if the tool is replaced.

## Procedure

1. Run the spindle unloaded at three speeds and listen for rumble or clicks.
2. Measure spindle vibration with the handheld analyser.
3. Compare with the reference spectrum recorded at commissioning.
4. Measure axial and radial play with a dial indicator.
5. Plan a bearing replacement if play or vibration exceeds the limits.
