# Replacing a worn cutting tool

> **Synthetic note.** Written for a personal portfolio project to demonstrate retrieval. It is not a real manufacturer procedure; do not use it on real equipment.

## When to use

Used when the tool wear counter approaches 200 minutes or when a tool wear failure (TWF) has been flagged.

## Procedure

1. Stop the spindle and apply lockout/tagout (see general-01).
2. Release the tool holder and remove the worn tool with the extraction key.
3. Clean the holder taper with a lint-free cloth; never use compressed air on the spindle nose.
4. Fit the new tool, torque the holder to the specified value and check runout below 0.01 mm.
5. Reset the tool wear counter to zero and run one test cycle at reduced feed.
