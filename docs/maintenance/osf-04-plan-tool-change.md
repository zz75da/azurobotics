# Planning tool changes to avoid overstrain

> **Synthetic note.** Written for a personal portfolio project to demonstrate retrieval. It is not a real manufacturer procedure; do not use it on real equipment.

## When to use

Overstrain combines wear and torque, so heavy cuts with a worn tool are the main risk.

## Procedure

1. Schedule heavy, high-torque jobs right after a tool change.
2. Run light finishing jobs on tools with more wear.
3. Review the wear-times-torque value at each shift handover.
4. Keep at least 15 % margin below the variant limit.
