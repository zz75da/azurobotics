# Returning a machine to service

> **Synthetic note.** Written for a personal portfolio project to demonstrate retrieval. It is not a real manufacturer procedure; do not use it on real equipment.

## When to use

After maintenance, the machine is restarted only after these checks.

## Procedure

1. Remove tools and cloths from the work area.
2. Refit all guards and covers.
3. Remove your padlock and tag, then switch on the main isolator.
4. Run one cycle at reduced feed and check temperatures, power and noise.
5. Sign the maintenance log and inform the operators.
