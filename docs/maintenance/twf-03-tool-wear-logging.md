# Monitoring and logging tool wear

> **Synthetic note.** Written for a personal portfolio project to demonstrate retrieval. It is not a real manufacturer procedure; do not use it on real equipment.

## When to use

Tool wear accumulates with machining time: the high-quality variant H adds 5 minutes per process, M adds 3 and L adds 2 in the AI4I data.

## Procedure

1. Export the wear counter of each machine at the end of the shift.
2. Compare wear against the 200 to 240 minute failure window.
3. Flag machines above 180 minutes for inspection the next morning.
4. Keep the history to estimate the real tool life of each product variant.
