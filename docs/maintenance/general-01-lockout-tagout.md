# Lockout/tagout before any intervention

> **Synthetic note.** Written for a personal portfolio project to demonstrate retrieval. It is not a real manufacturer procedure; do not use it on real equipment.

## When to use

Every procedure in this folder starts with isolating the machine from its energy sources.

## Procedure

1. Inform the operators and stop the cycle normally.
2. Switch off the main isolator and lock it with your personal padlock.
3. Attach a tag with your name and the date.
4. Release stored energy: air pressure, hydraulic pressure, capacitors.
5. Try to start the machine to confirm it is isolated.
