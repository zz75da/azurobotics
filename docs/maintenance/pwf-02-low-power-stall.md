# Diagnosing a low-power stall

> **Synthetic note.** Written for a personal portfolio project to demonstrate retrieval. It is not a real manufacturer procedure; do not use it on real equipment.

## When to use

Power below 3500 W during cutting usually means the spindle is not delivering enough torque at the requested speed.

## Procedure

1. Check the drive's fault history for under-voltage or current-limit events.
2. Verify the belt tension or coupling between motor and spindle.
3. Confirm the programmed speed and feed match the process sheet.
4. Run the spindle unloaded and compare the power with the reference value.
5. Escalate to an electrician if the unloaded power is also abnormal.
