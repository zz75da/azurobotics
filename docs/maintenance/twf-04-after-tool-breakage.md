# Checks after a tool breakage

> **Synthetic note.** Written for a personal portfolio project to demonstrate retrieval. It is not a real manufacturer procedure; do not use it on real equipment.

## When to use

After a tool wear failure the workpiece and the spindle may be damaged by fragments of the broken tool.

## Procedure

1. Lock out the machine and wait for the spindle to stop completely.
2. Remove all tool fragments from the work area and the chip conveyor.
3. Inspect the workpiece surface and quarantine it if gouged.
4. Check spindle runout before fitting a new tool.
5. Log the failure with the wear time at breakage.
