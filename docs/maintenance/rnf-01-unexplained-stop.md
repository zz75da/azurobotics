# Investigating an unexplained stop

> **Synthetic note.** Written for a personal portfolio project to demonstrate retrieval. It is not a real manufacturer procedure; do not use it on real equipment.

## When to use

AI4I includes random failures (RNF) with a probability of 0.1 % per process, independent of the measured parameters.

## Procedure

1. Note the exact time, the program line and the alarm text.
2. Check whether any of the other failure conditions (tool wear, heat, power, overstrain) were close.
3. Inspect the machine for loose cables or foreign objects.
4. Restart with one supervised cycle.
5. Log the event as random only if no cause is found.
