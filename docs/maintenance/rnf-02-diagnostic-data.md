# Collecting diagnostic data for intermittent faults

> **Synthetic note.** Written for a personal portfolio project to demonstrate retrieval. It is not a real manufacturer procedure; do not use it on real equipment.

## When to use

Random-looking failures are easier to explain when sensor data around the event is kept.

## Procedure

1. Export the last 30 minutes of temperature, speed, torque and wear readings.
2. Attach the alarm history from the controller.
3. Store the files with the failure record.
4. Review recurring events weekly to spot a hidden pattern.
