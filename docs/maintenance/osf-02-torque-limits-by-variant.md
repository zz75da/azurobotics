# Torque limits by product variant

> **Synthetic note.** Written for a personal portfolio project to demonstrate retrieval. It is not a real manufacturer procedure; do not use it on real equipment.

## When to use

The overstrain threshold depends on the product variant: the product of tool wear and torque must stay below 11,000 minNm (L), 12,000 (M) or 13,000 (H).

## Procedure

1. Identify the variant of the current batch from the product ID.
2. Compute the remaining margin: limit divided by current torque gives the maximum wear.
3. Program a tool change before that wear is reached.
4. Lower the torque by reducing depth of cut when the margin is small.
