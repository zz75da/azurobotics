# Low-speed operation and thermal derating

> **Synthetic note.** Written for a personal portfolio project to demonstrate retrieval. It is not a real manufacturer procedure; do not use it on real equipment.

## When to use

At low rotational speed (below 1380 rpm) the spindle moves less air, so heat dissipation depends more on the cooling system.

## Procedure

1. Avoid long cycles below 1380 rpm when the ambient air is warm.
2. If a job requires low speed, add pauses so the process temperature can drop.
3. Watch the process minus air temperature value on the panel during the job.
4. Stop the job if the difference stays below 8.6 K for more than five minutes.
