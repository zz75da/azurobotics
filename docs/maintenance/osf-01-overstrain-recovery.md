# Recovering from an overstrain failure

> **Synthetic note.** Written for a personal portfolio project to demonstrate retrieval. It is not a real manufacturer procedure; do not use it on real equipment.

## When to use

An overstrain failure (OSF) occurs in AI4I when tool wear multiplied by torque exceeds 11,000 minNm for variant L, 12,000 for M and 13,000 for H.

## Procedure

1. Stop the machine and lock it out.
2. Remove the tool; overstrain usually leaves it bent or chipped.
3. Inspect the workpiece and the fixture for movement.
4. Fit a new tool and reset the wear counter.
5. Restart with the torque limit check from osf-02.
