# Motor and inverter inspection

> **Synthetic note.** Written for a personal portfolio project to demonstrate retrieval. It is not a real manufacturer procedure; do not use it on real equipment.

## When to use

Repeated power failures can come from an ageing motor or inverter rather than the process.

## Procedure

1. Lock out the machine and discharge the inverter capacitors as specified.
2. Inspect cooling fins of the inverter and clean dust.
3. Measure motor winding insulation resistance with a megohmmeter.
4. Check motor bearings for noise by turning the shaft by hand.
5. Replace components outside tolerance and document the work.
