# Cooling system inspection

> **Synthetic note.** Written for a personal portfolio project to demonstrate retrieval. It is not a real manufacturer procedure; do not use it on real equipment.

## When to use

A heat dissipation failure (HDF) occurs in AI4I when the difference between process and air temperature is below 8.6 K and the rotational speed is below 1380 rpm.

## Procedure

1. Check that the cooling fans start with the spindle.
2. Measure air temperature and process temperature with the panel sensors.
3. If the difference is below 8.6 K, inspect the airflow path for blockage.
4. Verify the cabinet filter is not clogged; replace it if dust covers more than half of it.
5. Record both temperatures and the speed in the log.
