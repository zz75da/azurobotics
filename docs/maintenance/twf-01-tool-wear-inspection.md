# Tool wear inspection interval

> **Synthetic note.** Written for a personal portfolio project to demonstrate retrieval. It is not a real manufacturer procedure; do not use it on real equipment.

## When to use

In the AI4I 2020 dataset, tool wear failures happen when the tool is replaced or fails at a random wear time between 200 and 240 minutes.

## Procedure

1. Read the tool wear counter on the machine panel before each shift.
2. Inspect the cutting edge under a lamp from 180 minutes of wear onward.
3. Look for chipping, built-up edge and a dull, rounded profile.
4. Record the wear time and the visual result in the maintenance log.
5. Plan a replacement before 200 minutes when chipping is visible.
