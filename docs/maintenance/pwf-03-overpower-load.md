# Reducing cutting load after overpower

> **Synthetic note.** Written for a personal portfolio project to demonstrate retrieval. It is not a real manufacturer procedure; do not use it on real equipment.

## When to use

Power above 9000 W means the cut demands more than the drive should deliver, often from a high torque at high speed.

## Procedure

1. Reduce the feed rate by 20 % and repeat the cycle.
2. Check that the tool geometry matches the material.
3. Verify the workpiece clamping; vibration increases torque peaks.
4. If power is still above 9000 W, split the cut into two passes.
5. Update the process sheet with the new parameters.
